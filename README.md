# stella-sravanthi.dev

Personal portfolio: frontend engineer for communication products.

Built with Vite, React 19, TypeScript, and Tailwind CSS 4. No component library.

- Case studies follow problem, role, frontend decisions, tradeoffs, verification, result.
- Screenshot galleries are keyboard-accessible tab lists (arrow keys switch shots).
- Scroll reveal is CSS driven and disabled under `prefers-reduced-motion`.
- Screenshots come from a development environment with test data only.

## Run

```bash
bun install
bun dev        # local dev server
bun run build  # production build to dist/
```
